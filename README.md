# Портфолио Ирины Бродоцкой

Готовый статический сайт для GitHub Pages.

## Как опубликовать
1. Создать новый публичный репозиторий на GitHub, например `portfolio`.
2. Загрузить в корень репозитория `index.html`, `styles.css`, `script.js` и папку `assets`.
3. Открыть **Settings → Pages**.
4. В разделе **Build and deployment** выбрать **Deploy from a branch**.
5. Выбрать ветку `main`, папку `/ (root)` и нажать **Save**.

После публикации сайт будет доступен по адресу вида `https://USERNAME.github.io/portfolio/`.
